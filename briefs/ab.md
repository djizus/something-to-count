# Brief: which version

Two scenes from a novel exist in two versions each. Read the four files in `audit/ab/` and nothing else in this directory. You do not know the book and are not told which version is older.

For each scene, read version X and version Y in full, then answer in `audit/ab/verdict.md`:

1. Which version made you laugh or smile more? Quote the moments, from both.
2. Which version would make you more likely to read the next chapter, and why?
3. In which version is it clearer what each person in the scene wants?
4. Is there anything in the version you preferred that is worse than in the other?

Then one line for each scene: X or Y, and how sure you are, as a number from one to five.

Read as an ordinary reader of novels. Do not reward length, and do not reward a version for having more dialogue unless the dialogue did something for you. Be blunt. Nothing you write mentions any writing tool, model, vendor or session. Reply in two lines: your two verdicts.
